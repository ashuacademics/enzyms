# LC-MS Feature Processing Pipeline

This document describes a simple, step-by-step process for analyzing LC-MS data from biocatalytic experiments using the EnzyMS pipeline. The pipeline will:

1. **Detect and align** chromatographic features across .mzML file using [Asari](https://asari.readthedocs.io/). 
2. **Extract** the peak area matrix from the Asari results.  
3. **Compute** the exact m/z values of the substrate and anticipated products.  
4. **Process** and normalize the peak areas using background correction.  
5. **Select** the top significant peaks for further analysis. 
6. **Match** the selected peaks against the anticipated products list. 
7. **Visualize** the matched peaks using a scatterplot.  

---

## Pipeline Steps

### 1. Detect & Align Features with Asari

The pipeline begins by using the feature detection and alignment algorithms from [Asari](https://asari.readthedocs.io/) to identify mass-to-charge ratios (m/z) and retention times of compounds across all samples. Asari’s alignment algorithm matches similar features across runs while correcting for retention time shifts. Detection and alignment parameters are provided through the parameters.yaml file; while the default settings are generally effective, minor adjustments may be needed depending on the sample. This step also requires a reference sample, which the pipeline automatically selects as the first empty vector control (EVC) listed in the sample list file (list_of_samples.txt). An example command to run this step is:

```
asari process \
  --mode pos \
  --input "${mzml_dir}" \
  --reference "${mzml_dir}/${reference_evc}.mzML" \
  -o ${compound_name} \
  --parameter "$parameters.yaml"
```

### 2. Extract Feature Table (m/z, Retention Time, and Peak Areas)

After feature detection and alignment, the next step is to extract the feature matrix table generated by Asari. This table contains the detected m/z values, retention times, and peak areas for all samples. It serves as the starting point for downstream analysis, where peak areas will be further processed and interpreted.


### 3. Calculate the mass-to-charge ratio (m/z) of substrate and anticipated products

In this step, two Python scripts are used to calculate the expected m/z values for both the substrate and its potential products. The first script reads a SMILES file along with a YAML parameter file specifying the adduct type and ionization mode. It uses [RDKit](https://www.rdkit.org/) to generate the molecular formula for each substrate and [pyOpenMS](https://pyopenms.readthedocs.io/) to calculate the monoisotopic mass. The selected adduct is then applied to compute and output the substrate’s m/z values in a CSV file. The second script extends this process by simulating chemical variations (e.g., changes in the number of H, C, O, N, F, and Cl atoms) to generate a wide range of anticipated product formulas. It calculates and records the m/z values for all simulated products, producing a comprehensive list that will be used later to match detected features with predicted compounds.

Example commands to run these scripts are:

```
# Calculate substrate m/z
python3 scripts/calculate_substrate_mz.py \
  --input_file "$smi_file" \
  --output_file substrate_mz.csv \
  --parameters_file "$variations_param_file"
```

```
# Calculate anticipated product m/z
python3 scripts/calculate_anticipated_products_mz.py \
  --input_file "$smi_file" \
  --output_file Anticipated_products_mz.txt \
  --parameters_file "$variations_param_file"
```
### 4. Baseline adjustment

To reduce background noise, especially when working with samples such as cell lysates—empty vector controls (EVCs) are essential. These controls, which contain lysate without the gene of interest, help establish a baseline for non-specific or background peaks. The pipeline subtracts the background signal from each feature using the mean and standard deviation of peak areas in the EVC samples, ensuring that only significant signals are retained. The adjusted peak area is calculated using the following equation:

$$
\text{Peak Area}_{\text{adjusted}} = \text{Peak Area} - (\mu_{\text{evc}} + 3 \cdot \sigma_{\text{evc}})
$$

Where:  
- \( \mu_{\text{evc}} \) is the mean peak area in EVC samples  
- \( \sigma_{\text{evc}} \) is the standard deviation of peak areas in EVC samples

This filtering step ensures that only features with signal significantly above the EVC background are passed on for further analysis.

Example command to run this step:

```
python3 scripts/process_peak_area.py \
  --csv_directory ./ \
  --compound_mz_file substrate_mz.csv \
  --column_type_file "$list_of_samples_file" \
  --output_directory ./
```

### 5. Select Top Significant Peaks

This step of the pipeline identifies the most significant features (peaks) across all samples based on their background-adjusted peak areas. It processes a CSV file containing these adjusted values, along with a column type file that distinguishes different sample groups (e.g., enzyme samples vs. empty vector controls). Using parameters defined in the variations.param file, the script selects the top n most intense peaks (default: 100) and saves them to a CSV file for downstream analysis.

In addition to peak selection, the script generates a 3D mountain plot that visualizes how peak intensities vary across samples and retention times. This plot provides an intuitive overview of peak distribution, helping to highlight patterns and anomalies in the data.

The output includes:

- A 3D surface plot (`mountain_plot_*.png`) visualizing feature intensity across samples and retention times.

- A CSV file (`highest_peaks_*.csv`) listing the top peaks along with their sample name, m/z, retention time, and intensity.

Example command to run this step:

```
python3 scripts/get_significant_peaks.py \
  --input_files ./processed_${compound_name}.csv \
  --column_type_file "$list_of_samples_file" \
  --output_directory ./ \
  --param_file "$variations_param_file"
```

### 6. Match Significant Peaks Against Anticipated Products

This step matches the top significant peaks identified in each sample to a list of anticipated product m/z values generated earlier. It helps determine whether any detected features correspond to predicted biotransformation products.

The script reads the `highest_peaks_processed_*.csv` files (generated in the previous step) and compares each peak’s m/z value against the simulated product list (`Anticipated_products_mz.txt`). A match is considered valid if the absolute difference between the detected and anticipated m/z values is within a specified tolerance (default: 0.01 Da). Additionally, only peaks that match the substrate associated with the sample are retained.

For each matched peak, the script records the sample name, m/z, simulated formula, retention time, and intensity. The output for each sample is saved as `output_<SampleName>.csv` in the specified output directory.

The output includes:

  - Sample name
  - Observed m/z
  - Matching substrate
  - Simulated m/z
  - Simulated formula
  - Retention time
  - Peak intensity

Example command to run this step:

```
# Match simulated products file
python3 scripts/match_significant_peaks_with_anticipated_mz.py \
  --input_dir ./ \
  --reference_file Anticipated_products_mz.txt \
  --output_dir ./ \
  --tolerance 0.01
```

### 7. Visualize matched peaks

This step generates scatterplots to visualize matched m/z values across samples. Isotopic peaks—such as those differing by ~1.00335 Da—and isotopic variants of known substrates are excluded to enhance clarity. Each feature is plotted with m/z on the x-axis and intensity on the y-axis, with samples differentiated by distinct colors and marker styles. This visualization allows for intuitive comparison of signal distribution across enzyme-treated samples.

Example Command:

```
python3 scripts/plot_scatterplot_matched_peaks.py
--input_dir ./
--output_dir ./
--substrate_mz_file substrate_mz.csv
--sample_file "$list_of_samples_file"
```
