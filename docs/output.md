### 📁 Output Files Overview

Running the EnzyMS pipeline creates an output directory containing all intermediate and final result files. These files represent the progression through each step of the pipeline, from feature detection to product matching and visualization.

Below is a summary of the key output files:

---

#### 🧪 `(compound_name)_areas.csv`

- Output of feature detection and alignment using Asari.
- Contains detected m/z values, retention times, and peak areas for all samples.
- Serves as the starting point for downstream processing.

---

#### ⚗️ `substrate_mz.csv`

- Lists the calculated mass-to-charge ratios (m/z) of substrates.
- Computed using [RDKit](https://www.rdkit.org/) and [pyOpenMS](https://pyopenms.readthedocs.io/) based on SMILES and ionization/adduct parameters.
- Used to identify and exclude substrate isotopes during downstream steps.

---

#### 🧬 `Anticipated_products_mz.txt`

- Contains a list of simulated molecular formulas for anticipated products.
- Generated by applying defined atom-wise variations (e.g., ±1 or more atoms of H, C, O, N, F, Cl) to the substrate, simulating potential structural modifications resulting from enzymatic activity.
- Each formula's m/z is computed with [RDKit](https://www.rdkit.org/) and [pyOpenMS](https://pyopenms.readthedocs.io/).
- Used for matching detected features with possible biotransformation products.

---

#### 📉 `processed_(compound_name).csv` and `transposed_(compound_name).csv`

- Result of background correction using empty vector controls (EVCs).
- Peak areas are adjusted using the formula:

  $$
  \text{Peak Area}_{\text{adjusted}} = \text{Peak Area} - (\mu_{\text{evc}} + 3 \cdot \sigma_{\text{evc}})
  $$

  Where:
  - \( \mu_{\text{evc}} \): mean EVC signal
  - \( \sigma_{\text{evc}} \): standard deviation of EVC signal

- `processed_*.csv`: standard format with features in rows.
- `transposed_*.csv`: transposed format with features in columns.

---

#### 🔺 `highest_peaks_processed_(compound_name).csv`

- Lists the top N significant peaks after background correction.
- Peaks are selected based on intensity and relevance to enzyme-treated samples.
- Used for product matching and visualization.

---

#### 🌄 `mountain_plot_processed_(compound_name).png`

- A 3D mountain plot visualizing peak intensity by retention time and sample.
- Helps identify trends and standout peaks across samples.

---

#### 🧬 `output_(compound_name).csv`

- Lists all detected m/z values that matched those in `Anticipated_products_mz.txt`.
- Includes details such as:
  - Observed m/z
  - Simulated molecular formula
  - Simulated m/z
  - Sample name
  - Retention time
  - Peak intensity

---

#### 📊 `scatter_plot_output_(compound_name).png`

- A scatterplot of matched m/z values across samples.
- Isotopic peaks are filtered out.
- Samples are color-coded and marked distinctly for visual comparison.

---

These files collectively allow for interpretation, filtering, comparison, and visualization of enzymatic biotransformation data processed through the EnzyMS pipeline.

### 🔍 Additional Analysis and Visualization Tools

In addition to the core output files, the EnzyMS pipeline provides utility scripts for deeper analysis of individual features and comparison across samples.

---

#### 📈 Compare Extracted Ion Chromatograms (EIC)

To visualize the extracted ion chromatograms (EIC) of a specific product m/z across multiple `.mzML` files, use:

#### Script: `plot_peaks.py`

```
python3 plot_peaks.py \
  --input sample1.mzML sample2.mzML sample3.mzML \
  --product 391.123 \
  --tolerance 0.01 \
  --sample_file list_of_samples.txt \
  --output eic_comparison.png
```
##### Description
- Plots extracted ion chromatograms for the specified m/z value.
- Compares retention time profiles across multiple samples.
- Useful for visually verifying peak consistency or differences.


#### 📈 Compare Product and Substrate in Sample vs. Control

To compare the peak intensity of a substrate and its product between a sample and its corresponding EVC, use:

#### Script: `plot_substrate_product_peak_with_evc.py`

```
python3 plot_substrate_product_peak_with_evc.py \
  --input sample_XYZ.mzML \
  --control evc_XYZ.mzML \
  --substrate 273.091 \
  --product 289.107 \
  --tolerance 0.01 \
  --output sample_vs_evc.png
```
##### Description
- Overlays the substrate and product peaks in both sample and EVC.
- Visualizes how enzymatic activity alters peak profiles.
- Helpful for confirming whether the product is enzyme-specific.
